# Spiko design system

Storybook for `@spiko-tech/design-system`. This standing branch is the **spiko-landing** consumer pin (not for merge onto `main`).

## Browse

- **UI** — buttons, badges, cards, tabs, accordion, …
- **Inputs** — text, date, select, combobox, OTP, …
- **Feedback** — progress, toast
- **Overlay** — dialog, sheet, popover, dropdown, Spiko dialog
- **Data** — table, pagination, chart, carousel, sidebar
- **Icons / Logos / Tokens** — brand assets still in this repo

Stories for product-only components that left this package (IBAN, phone, amount, markdown, status, web3 icons, share-class tokens, …) were dropped.
